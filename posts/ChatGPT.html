LLMShare: When Trusted AI Links Become Malware Delivery

01 June 2026 6 min read Eugene Myburgh

A new campaign dubbed LLMShare is turning one of the most trusted platforms on the internet—AI chat tools—into a malware delivery mechanism. By abusing ChatGPT share links and hiding malicious content behind legitimate domains, attackers are bypassing traditional security controls and exploiting user trust at scale.

Intro / Context

In May 2026, researchers uncovered a malvertising campaign where threat actors abused ChatGPT’s sharing feature to host fake outage pages. These pages appear on legitimate chatgpt.com URLs, making them highly believable and difficult for both users and security tools to detect.

Instead of traditional phishing sites hosted on suspicious domains, attackers now leverage trusted platforms themselves. Victims are lured via malicious Google ads and SEO poisoning, landing on what looks like an official ChatGPT page—but it’s actually weaponized content generated using the platform itself.

Main Findings

The attack chain is simple, but highly effective:

  • Users search for “ChatGPT” or related terms
  • They click a malicious sponsored ad
  • The link leads to a legitimate ChatGPT share page
  • The page displays a fake “service outage” message
  • Users are prompted to download a “desktop app”
  • The download delivers malware

What makes this attack dangerous is the use of a trusted domain. Since the initial page lives on chatgpt.com, traditional URL filtering and security validation mechanisms fail to flag it as malicious.

Key insight: This attack isn’t about breaking security tools—it’s about bypassing them entirely by abusing trusted infrastructure.

Technical Detail

Attackers are using ChatGPT’s code rendering capabilities to generate fully styled HTML pages directly within shared links. These pages mimic official outage notifications and include download buttons that redirect victims to attacker-controlled infrastructure.

Once redirected, victims land on a fake OpenAI download portal (e.g., openew[.]app) which serves malware tailored for both Windows and macOS systems, often deploying credential-stealing payloads.

Indicators llmshare-iocs.txt 
# Suspicious patterns seen in LLMShare campaigns

chatgpt.com/s/*            # Legitimate share links used maliciously
openew[.]app              # Fake ChatGPT download site
"high traffic" outage msg # Social engineering lure
download desktop app      # Trigger phrase

# Behavioral indicator
User redirected from trusted domain to external download site

Impact and Recommendations

The LLMShare campaign highlights a major shift in attacker tactics—moving from fake domains to abusing real, trusted platforms. This significantly increases success rates, as users are trained to trust domains like ChatGPT.

Key risks:

  • Credential theft (browser passwords, session cookies)
  • Malware infection on both macOS and Windows
  • Bypassing traditional URL filtering and reputation checks

Recommended mitigations:

  • Educate users: trusted domain ≠ trusted content
  • Block or inspect outbound downloads from unknown domains
  • Avoid clicking sponsored ads for software downloads
  • Validate software sources manually (go directly to vendor sites)
  • Implement browser isolation or advanced threat protection
Warning: Legitimate services will never ask you to download software just because their website is “down.”
